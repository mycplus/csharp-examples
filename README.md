# csharp-examples

C# source code examples accompanying programming tutorials on [MYCPLUS.com](https://www.mycplus.com/). Each example lives in its own directory with its own README, tests and GitHub Actions workflow, so each article's build badge reflects only that article's code.

## Examples

| Name | Description | Status |
| --- | --- | --- |

| [Prime Numbers](math/prime-numbers/) | Trial division up to the square root and the Sieve of Eratosthenes | [![Prime Numbers](https://github.com/mycplus/csharp-examples/actions/workflows/prime-numbers.yml/badge.svg)](https://github.com/mycplus/csharp-examples/actions/workflows/prime-numbers.yml) |
| [Insertion Sort](sorting/insertion-sort/) | Stable insertion sort that shifts larger elements right | [![Insertion Sort](https://github.com/mycplus/csharp-examples/actions/workflows/insertion-sort.yml/badge.svg)](https://github.com/mycplus/csharp-examples/actions/workflows/insertion-sort.yml) |
| [Selection Sort](sorting/selection-sort/) | Selection sort with at most n - 1 swaps | [![Selection Sort](https://github.com/mycplus/csharp-examples/actions/workflows/selection-sort.yml/badge.svg)](https://github.com/mycplus/csharp-examples/actions/workflows/selection-sort.yml) |
